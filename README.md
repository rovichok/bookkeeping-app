# Lentis Business Platform

> A production-ready full-stack business platform built with React, ASP.NET Core, and modern cloud infrastructure.

Lentis is a cloud-hosted application designed to simplify business operations by providing secure administrative workflows, lead management, and a foundation for bookkeeping and financial process automation.

This project demonstrates the complete software engineering lifecycle—from application architecture and secure authentication to cloud deployment, production hardening, and operational maintenance.

---

# Why Lentis?

Many small businesses rely on disconnected systems for customer inquiries, bookkeeping, and daily operations. This often leads to duplicate work, manual processes, and fragmented data.

Lentis was created to serve as a centralized platform that streamlines these workflows while providing a secure and scalable architecture for future business applications.
